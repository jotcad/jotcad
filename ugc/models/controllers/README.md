# Controller Accessories & Replacements

This directory contains modular CAD model recipes for gamepad components, adapters, and extended joysticks.

## Models

* **`moga_thumbstick.jot`**: Parametric MOGA Hero/Pro analog stick controller cap and stem unit (`controllers/moga_thumbstick`).
* **`moga_hex_clamshell.jot`**: Low-profile printable split-half hexagonal adapter that clamps over the MOGA thumbstick (`controllers/moga_hex_clamshell`).
* **`moga_hex_socket.jot`**: Female hexagonal mating socket collar with a continuous $\varnothing 27\text{ mm}$ cylindrical rim (`controllers/moga_hex_socket`).
* **`moga_extension_stick.jot`**: Extended joystick column with an integrated female hexagonal socket and ergonomic thumb dish (`controllers/moga_extension_stick`).
